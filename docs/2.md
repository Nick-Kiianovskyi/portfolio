# Лог работ — 2026-10-20 (часть 2)

> Исторический лог. Структура ниже приведена к актуальному состоянию сайта:
> две языковые версии и две страницы опыта.

## Задача

Фиксированный Header: Logo, Navigation (Home, Projects, Experience,
Contact), Language Switcher (UA | EN), кнопка Download CV. Адаптив под
мобильные устройства. Без JavaScript.

## Что сделано

### HTML (все 4 страницы)

Новая разметка header:

```html
<header class="site-header">
  <div class="header-inner">
    <a class="site-logo" href="index.html">…</a>
    <input type="checkbox" id="nav-toggle" class="nav-toggle">
    <label for="nav-toggle" class="nav-toggle-label">…</label>
    <div class="header-menu">
      <nav class="site-nav">…</nav>
    </div>
    <nav class="lang-nav">…</nav>
  </div>
</header>
```

- **Mobile-меню без JS:** CSS-only гамбургер на чекбоксе
  (`input.nav-toggle` + `label`) — `.nav-toggle:checked ~ .header-menu`
  показывает выпадающее меню. Лейбл скрыт на ≥72rem.
- **Download CV:** ссылки в hero и на страницах опыта ведут на актуальные PDF
  (`files/cv_fullstack_kiianovskyi.pdf`, `files/cv_SAP_SD_consultant.pdf`),
  атрибут `download` — файл скачивается, а не открывается вкладкой.
- **Якоря:** на главных страницах есть `id="projects"` и `id="contact"`,
  на страницах опыта — `id="experience"`. Навигация ведёт на
  `index.html#projects`, `index.html#contact` и
  `work_experience_UA.html` / `work_experience_EN.html`.

### CSS (css/style.css)

- `.site-header { position: fixed; top: 0; }` + `z-index: 100`,
  компенсация высоты через `body { padding-top: var(--header-height) }`
  (`--header-height: 3.75rem` на мобильном, `4rem` на ≥72rem).
- `html { scroll-padding-top: var(--header-height) }` — якорные переходы
  не прячутся под фиксированной шапкой; на десктопе, где шапка статична,
  отступ обнуляется.
- Мобильное меню: `.header-menu` — абсолютный выпадающий блок
  (`position: absolute; top: 100%`), пункты столбцом.
- Десктоп (≥72rem): `.header-menu` — flex-строка, гамбургер скрыт,
  меню всегда видно.
- `.visually-hidden` — утилита для скрытого текста («Меню») у лейбла.
- Mobile First сохранён: используются только `@media (min-width: …)`.
