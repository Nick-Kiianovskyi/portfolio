# Лог работ — 2026-10-20 (часть 2)

## Задача

Фиксированный Header: Logo, Navigation (Home, Projects, Experience, Resume,
Contact), Language Switcher (UA | EN), кнопка Download CV. Адаптив под
мобильные устройства. Без JavaScript.

## Что сделано

### HTML (все 6 страниц)

Новая разметка header:

```html
<header class="site-header">
  <div class="header-inner">
    <a class="site-logo" href="index.html">…</a>
    <input type="checkbox" id="nav-toggle" class="nav-toggle">
    <label for="nav-toggle" class="nav-toggle-label">…</label>
    <div class="header-menu">
      <nav class="site-nav">…</nav>
      <nav class="lang-nav">…</nav>
      <a class="btn-download" href="…pdf" download>Download CV</a>
    </div>
  </div>
</header>
```

- **Mobile-меню без JS:** CSS-only гамбургер на чекбоксе
  (`input.nav-toggle` + `label`) — `.nav-toggle:checked ~ .header-menu`
  показывает выпадающее меню. Лейбл скрыт на ≥48rem.
- **Download CV:** `href` указывает на PDF текущего языка
  (`files/Nikolay-Kiyanovskiy-UA.pdf` для RU/UA-страниц,
  `files/Nikolay-Kiyanovskiy-EN.pdf` для EN), атрибут `download` —
  файл скачивается, а не открывается вкладкой.
- **Якоря:** добавлены `id="projects"` и `id="contact"` на index-страницы,
  `id="experience"` на resume-страницы. Навигация ведёт на
  `index.html#projects`, `resume.html#experience`, `index.html#contact`.

### CSS (css/style.css)

- `.site-header { position: fixed; top: 0; }` + `z-index: 100`,
  компенсация высоты через `body { padding-top: var(--header-height) }`
  (`--header-height: 3.5rem`, на ≥48rem — `4rem`).
- `html { scroll-padding-top: … }` — якорные переходы не прячутся под шапкой.
- Мобильное меню: `.header-menu` — абсолютный выпадающий блок
  (`position: absolute; top: 100%`), пункты столбцом.
- Десктоп (≥48rem): `.header-menu` — flex-строка, гамбургер скрыт,
  меню всегда видно.
- Кнопка `.btn-download` — акцентный фон, увеличенный hit-area.
- `.visually-hidden` — утилита для скрытого текста («Меню») у лейбла.
- Mobile First сохранён: используются только `@media (min-width: …)`.

## Решения / отклонения от ТЗ

- ТЗ просило переключатель **UA | EN**, но на сайте три языковые версии
  (RU в корне, UK, EN). Полностью убрав RU из навигации, русская версия
  стала бы недостижимой из интерфейса. Решение: переключатель
  **UA | EN | RU** на всех страницах — каждый язык достижим.
  На EN/UK-страницах порядок: UA, EN, RU; в корне: RU, UA, EN.
- На resume-страницах пункт «Experience» ведёт на собственный якорь
  `#experience`, на index-страницах — на `resume.html#experience`
  (раздела с опытом на главной нет).
