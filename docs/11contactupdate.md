# Лог работ — Contact обновление

## Задание
- Убрать большую кнопку Contact me

- Поднять значки контактов под фото в начале сайта

## Реализация

### Hero (index.html, uk/index.html, en/index.html)
Добавлен блок `.hero-contacts` сразу под `<figure class="hero-media">` в hero-секции. Содержит только иконки (Email, GitHub, LinkedIn, Telegram) без текстовых адресов. Ссылки ведут на реальные адреса, без JavaScript.

### Контакты
Секция `contact-section` при необходимости очищена — главные контакты вынесены в hero. Иконки стилизованы круглыми с hover-эффектом.

### Стили (css/style.css)
Добавлены стили `.hero-contacts`, `.contact-list--icons`, `.contact-icon-link`.
