# Лог работ — 2026-10-20

## Задача

Создать структуру персонального сайта-портфолио: HTML5, CSS3, без JavaScript,
Mobile First, Responsive Design, тёмная тема, семантическая вёрстка,
поддержка двух языков и трёх форматов представления контента.

## Созданная структура

```
/
├── index.html              # RU — главная (корень = язык по умолчанию)
├── resume.html             # RU — резюме
├── uk/
│   ├── index.html          # UK — главная
│   └── resume.html         # UK — резюме
├── en/
│   ├── index.html          # EN — главная
│   └── resume.html         # EN — резюме
├── css/
│   ├── style.css           # базовая тема (Mobile First, тёмная тема)
│   ├── resume.css          # раскладка резюме
│   └── print.css           # стили для печати (media="print")
├── files/
│   ├── Nikolay-Kiyanovskiy-UA.pdf   # заглушка
│   └── Nikolay-Kiyanovskiy-EN.pdf   # заглушка
├── images/
│   └── .gitkeep
└── favicon.ico             # заглушка
```

## Решения по архитектуре

- **Языки:** три версии — RU (корень `/`), UK (`/uk/`), EN (`/en/`).
  Пути между версиями относительные, с учётом вложенности (`../css/`, `../files/`).
- **Три формата контента:**
  1. HTML-страницы;
  2. PDF-файлы резюме в `files/`;
  3. Печатная версия — `print.css` подключён через `media="print"` на всех страницах.
- **Тёмная тема:** цвета вынесены в CSS-переменные (`:root`) —
  `--color-bg`, `--color-surface`, `--color-text`, `--color-accent` и др.
- **Mobile First:** стили пишутся от мобильной вёрстки, адаптив —
  медиазапрос `@media (min-width: 48rem)` (сетка карточек в 2 колонки, крупнее заголовки).
- **Семантика:** `header`, `nav`, `main`, `section`, `article`, `footer`,
  заголовки `h1–h3`, `aria-labelledby` для секций, `aria-current` для активных ссылок.
- **SEO:** на каждой странице добавлены `hreflang`-альтернативы,
  связывающие три языковые версии.
